# Repos excluded from the Bubblesort dataset.
#
# The top of GitHub by stars is dominated by things that are not software:
# awesome-lists, interview prep, roadmaps, book collections, tutorial series.
# They carry 100k+ stars each, which makes them completely unguessable — and one
# of them in a puzzle turns the whole board into noise.
#
# The test for inclusion: is this a codebase a developer could reason about?
# "Could an informed person think their way to where this ranks?" If the answer
# is no, it belongs here.
#
# Syntax: one pattern per line, matched case-insensitively against the full
# "owner/name" slug. `*` matches any run of characters. `#` starts a comment.
# Re-running build-dataset.ts prints everything this file cut, plus the repos it
# kept that look suspicious, so this list can be tightened over time.

# --- star farms --------------------------------------------------------------
# The 2025-26 cohort: prompt dumps, "skills" lists, agent registries, leaked
# system prompts. These spike to 40-190k stars in months and are documents, not
# codebases, so nobody can reason about where they rank on any engineering stat.
#
# There is no structural signal that separates them. Hmbown/CodeWhale carries
# 195 contributors and 6,225 commits, statistically indistinguishable from
# charmbracelet/bubbletea at 155 and 1,869 -- while anthropics/claude-code, which
# is obviously real, has only 54 contributors and 713 commits. Contributor
# counts, commit counts and stars-per-commit all misfire in both directions.
# What actually separates them is recognition, which no API exposes, so this
# stays a hand-maintained list. The note called it: filter by hand.

# Plural on purpose. "*prompt*" also swallows linshenkx/prompt-optimizer, which
# is a real application; "*prompts*" reaches the dumps and collections without it.
*prompts*
# Bare suffix too: "marketingskills" runs the words together and slips a
# separator-anchored pattern.
*skills
*-skill
*/agents
*workflows*
# Hyphen/underscore anchored, because a bare "*leaks*" eats gitleaks/gitleaks —
# a genuine secret scanner.
